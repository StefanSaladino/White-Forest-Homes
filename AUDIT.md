# Local review checks

Run `npm run validate` for links, responsive images, metadata, JSON-LD, image dimensions, accessible names and target IDs. Run `npm run check:js` for JavaScript syntax.

This package has not been visually tested in a browser in this session. Test mobile/desktop layout, navigation, portfolio filtering, full-size image links, consent settings and the email inquiry preview locally. Live form processing and Google Ads conversion verification require the production host and real tracking IDs.
