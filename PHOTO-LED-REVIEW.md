# Photo-led redesign

The public navigation has six destinations: Home, Projects, Services, Process, About and Contact. Privacy and form confirmation remain as utility pages.

- Home opens with the existing White Forest tree mark and wordmark, followed by the church kitchen and the second custom home's winter exterior.
- Projects has one gallery with all 40 original photos. Filters cover renovations, additions, both custom homes, and custom carpentry.
- Services has four short descriptions with photos. Process has a dedicated page with four steps and project photography.
- About and Contact retain their content and layouts apart from the shared navigation and removal of captions. The About photo is still a placeholder for Danny's future headshot.
- Photo descriptions appear in the enlargement dialog for gallery images. Hero and supporting photos are static.
- Legacy HTML files are redirects only. On Netlify the redirect rules cover retired routes; the former Renovations & Additions page uses the static redirect so the old Additions anchor can still be distinguished. Static redirects also work on GitHub Pages. They preserve campaign query strings with JavaScript. Only retained pages are in the sitemap.

Review on the branch before changing hosting, production, or Google Ads destinations.
